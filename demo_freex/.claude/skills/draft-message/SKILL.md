# Drafting messages to collaborators

File: `ops/drafts/AAAA-MM-GG-recipient-topic.md`

```
BOZZA — non inviata
to: <name> (<role>) | channel: <from ops/contacts.md or [ASK]> | language: <from contacts or [ASK]>
goal: <the one answer we need> | answer needed by: DD.MM | blocks: T-…
---
<message>
---
notes for Giordana: <what to check before sending; open points>
```

## Rules
- One message = one clear ask (or a short numbered list the recipient can answer item by item: "ok / no / date").
- Ask, don't assume: dates, scope, costs are questions until answered. Never write as if something were agreed.
- Short, warm, practical; Giordana's tone (informal "tu" in Italian unless contacts.md says otherwise). No brand manifesto in operational messages.
- Name things exactly (DEMO_FREEX, free.session_01, P02…). Mentioning a term only to ask for its removal (e.g. "MADE IN ITALY", "demo_920" on the DTF template) is allowed in drafts to Marta.
- Language unknown → write in Italian and flag `[ASK: language]`.
- After Giordana sends it she records it with `/decide` or `/change` ("sent to Marta 26.10"); the planner then schedules a follow-up check (4 days).
