# drop — backward checklist (D = release/preorder day)

| when | task | owner |
|---|---|---|
| D-6w | scope: items, editions, quantities, price → decided by Giordana (`numbers`) | giordana |
| D-6w | technique per item (DTF / screen print / embroidery) + printer shortlist | research |
| D-5w | print-ready files with sizes and placement (not mockups) | designer (confirmed dates) |
| D-5w | colour proofs (several variants) → Giordana chooses | designer → giordana |
| D-4w | quotes from printers, sample if possible | giordana ↔ printer |
| D-3w | production (≈3 weeks) | printer |
| D-3w | hangtag (QR on hangtag, not on garment) + label with logo and QR | designer |
| D-2w | preorder page/state, terms, payment method | site (decision first) |
| D-2w | product content: free.pieces posts, stories | social/design |
| D | open preorder / release | giordana |
| D+? | fulfilment: pickup at event / shipping | giordana |
| D+2w | `/retro` | planner |

Never: "MADE IN ITALY"; QR printed on the garment; numbers not given by Giordana.
