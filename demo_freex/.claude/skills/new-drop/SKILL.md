# /new-drop

1. Create goal via `/goal` (name as given; use the free.quencies naming, e.g. free.track_02).

3. Scope/quantities/prices → decisions.md (with `numbers` scenarios if inputs exist).
4. Reply in Italian: critical path + first decisions.
