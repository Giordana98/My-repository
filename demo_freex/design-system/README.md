Local mirror of the **DEMO_FREEX Design System** in Claude (Artifact, type "Design System").
- Claude artifact: https://claude.ai/artifact/5Hww7RdVFWcebYH1zEbrJY (private — share from its page if needed)
- `artifact/` — source files of that artifact (`project/` content). Edit here, publish with the Artifact tool (url above, root = this folder's parent copy), keep both in sync. Logo/drawing uploads: ids in `artifact/design-system.json`.

- `components.md` — the three levels, logo rules, indicator, formats, first templates
- `inventory.md` — **whitelist** of every asset allowed in outputs

The design agent keeps artifact and mirror in sync. The site imports `tokens.css`.
